# 《西山不是山》· 中小型原创音乐剧 · 剧目站

> 一夜。一间屋。一扇门。

昆明西山睡美人题材音乐剧《西山不是山》的线上展演站。14 场、78 分钟、7 首唱段，
完整剧本正文与全部唱段歌词对外公开。

线上地址：<https://zhouyaobai.github.io/shanhe-baiduren/xishan/>

## 一、这是什么站

同源 NOCTURNE 视觉体系（手绘钢笔排线 + 蚀刻质感 + 巨标题），但**重定了色谱**：

| | 《山河摆渡人》 | 《西山不是山》 |
|---|---|---|
| 底色 | 朱砂红（火塘、彝寨、1932—35） | 墨青（滇池夜、雾、一盏煤油灯） |
| 唯一光源 | 火塘（三层暖色） | 煤油灯（一点金） |
| 场次 | 六幕 · 46 首 | 14 场 · 7 首 |
| 3D | 火塘粒子 + 远山 | 滇池对岸的睡美人山形 + 水面 + 塔院屋脊 |

三色封顶：墨青（夜/水）· 宣纸白（雾/光）· 朱砂（门/血）。不出现第四色相。

## 二、核心机制：讲述即演出

当守塔人开口，传说中的人物从光里走出来，站到堂屋里；他一停，他们退回光里。

讲的人与被讲的人同处一室——于是第四幕那场争执无法回避：学生甲要更正传法，
可更正的对象就站在她旁边，由守塔人的嘴讲出来。

**退场动作本身就是"她不存在"的可见证据。**

## 四、3D 场景

`assets/js/scene.js` —— Three.js + 手写排线着色器（复用 NOCTURNE 的 `hatch.js`）。

构图依据西山景区官方地貌描述：
**腿**云盘山与碧鸡山 · **腹**华亭山与太华山 · **胸**罗汉山与挂榜山（龙门石窟正在此处）
· **脸**大青山 · **发**观音山黑荞母片区。最佳观赏点为海埂大坝，故相机置于水面南岸。

层次：远景山脊 4 层（排线密度递增）→ 中景卧人形剪影 → 排线水面 → 近景塔院屋脊与灯。

滚动即"拉开山色"：雾散、相机推进、山层视差。

> 排线密度恒定铺满表面，体积感另由「法线 vs 光向」承担——若用光照驱动排线，
> 亮部会完全无线，物体退化为平涂色块。详见 `assets/nocturne/docs/视觉规范.md`。

## 五、构建

```bash
./xishan/tools/build.sh [剧本.md]
```

流程分层，勿合并：

```
剧本 .md
  └─ extract_script.py   解析层 → working/script_struct.json
       └─ gen_site_data.py   映射层 → assets/js/data.js
  同时 gen_svg.py 生成铜版画线稿 → assets/svg/*.svg
```

解析层只管解析，映射层只管结构→语义。剧目信息、人物卡、伏笔等人工撰写的内容
集中在 `gen_site_data.py` 顶部的常量区，改内容不动解析器。

## 七、校验

`build.sh` 末尾自动校验：文件齐全、幕/场/唱段数、CSS 变量无未定义、JS 引用的 id 均存在。

`tools/shot.mjs` 起本地静态服务并用 CDP 驱动 Chrome，输出页面指标与控制台错误：

```bash
node xishan/tools/shot.mjs xishan/ /tmp/shots 1440 900
```

## 八、素材出处

故事取材于昆明西山睡美人民间传说；参照「1903 年云南石屏人袁嘉谷获经济特科一等第一名」
等公开史料。聂耳生平依公开资料，墓园二十四级台阶象征其生命历程一节为剧作有意保留的错位。
