# 《百年星语·破晓1928》· 内容源与审查记录

这个目录放的是**剧本站点的"源"**，不是产物。
产物在仓库根的 `px1928/`（构建出来的静态站点）。

| 文件 | 是什么 | 能公开吗 |
|---|---|---|
| `site_meta.json` | 剧目内容源：人物小传、歌单目录、伏笔结构、时间轴、配色、首页文案 | 能 —— 与站点公开层同级别 |
| `REVIEW.md` | 设计与审查记录：历轮改动的回归数据、对比度实测、3D 门控验证、已知边界 | 能 —— 纯技术文档，不含剧本原文 |

## 剧本本体不在这里

原始 docx（含全部台词与歌词）**绝不进仓库**。它放在 iCloud Drive：

```
~/Library/Mobile Documents/com~apple~CloudDocs/剧本/《百年星语·破晓1928》云南本土红色歌剧.docx
```

## 改内容怎么走

1. 改 `site_meta.json`（改人物、伏笔、歌单说明、配色…）
2. 跑 `bash scripts/rebuild-px1928.sh`
3. 构建会打印对比度实测与「剧本每一段文字都在站点上（缺失 0）」，确认再上线
4. `bash scripts/deploy-site.sh`

> `data.js` 每次重建都会变 —— 加密用随机 salt，这是对的，不是改动。
